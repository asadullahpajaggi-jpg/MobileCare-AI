# MobileCare AI

### Intelligent Android Mobile Troubleshooting Expert System

MobileCare AI is a Python-based rule-driven expert system designed to identify and troubleshoot common Android smartphone problems.

## Main Features

- Battery troubleshooting
- Charging problems
- Network and connectivity issues
- Screen and touch problems
- Mobile performance issues
- Camera and audio problems
- Intelligent diagnosis and solutions

## Expert System Components

- Knowledge Base: 100 IF-THEN Rules
- Assertions: 300 Facts
- Inference Engine
- Forward Chaining
- Backward Chaining
- Natural Language Interface

## Technologies

- Python
- Streamlit
- MySQL
- SQLite (optional for local testing)
